# Finpass-AI Next.js application

This directory is the production Node.js application for Finpass-AI. It serves the current UI from `public/static-pages` and exposes the API under `/api`.

## Vercel

Set the Vercel project Root Directory to `next-app`, use the Next.js framework preset, and add the variables from `.env.example` in the Vercel project settings. Never commit provider keys.
